# Altapete Solutions - Pixel-Perfect Clone

A complete, high-fidelity, pixel-to-pixel clone of **[Altapete Solutions](https://altapetesolutions.com/)** built with **Next.js & React**.

## Features Included
- **All 29 Routes (38 Static Pages Prerendered)**:
  - Homepage (`/`) with interactive typewriter hero, stats counters, tech stack marquee, and client logo slider
  - Solutions Mega Menu with dual-column layout (Digital Transformation & Integration)
  - Services dropdown and individual service pages
  - Products dropdown and individual product pages
  - Complete Knowledge Hub / Blog system with full articles and related guides
  - Company profile, Careers, What We Do, and Contact Us pages
  - Custom 404 page
- **Interactive Mega Menu & Mobile Drawer**:
  - Full desktop hover mega menu with gradient card and categorized services
  - Mobile responsive drawer with accordion navigation
  - Sticky animated header with logo transitions
- **Assets & Styling**:
  - Full original CSS styling bundle with base64 embedded fonts and SVG icons
  - Technology partner marquee and client logo infinite scroll animations
  - Responsive layout optimized for mobile, tablet, and desktop

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```

### 4. Deploying to Vercel
1. Push this repository to GitHub.
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import this repository.
4. Framework preset will automatically detect **Next.js**.
5. Click **"Deploy"** — it builds and deploys in seconds with zero extra configuration!
